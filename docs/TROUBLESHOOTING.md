# 🛠️ استكشاف الأخطاء

| العَرَض | السبب المحتمل | الحل |
|---|---|---|
| **البوت متوقف / «غير متصل»** في `/admin` | العملية متوقفة، توكن خاطئ/مُعاد ضبطه، قاعدة البيانات لا تقبل الاتصال، المنصة أنامت الخدمة | راجع سجل العملية (`pm2 logs` / `docker logs`). تأكد من `DISCORD_TOKEN` و`DATABASE_URL`. اختبر `/health`. على المنصات التي تنام فعّل UptimeRobot |
| **الأزرار تقول «فشل التفاعل»** أو لا تستجيب | البوت متوقف، أو وضع الصيانة مفعّل، أو الوحدة معطّلة، أو رسالة قديمة بعد تغيير معرّفات | افتح `/admin` (الصيانة/الحالة). فعّل الوحدة من الإعدادات. أعد نشر اللوحة من اللوحة بزر «نشر/تحديث» |
| الزر يردّ «انتظر قليلاً» | فاصل منع التكرار (cooldown) | طبيعي، انتظر ثانية |
| **ProBot لا يُكتشف** | معرّف البوت أو المستلم خطأ، أو نمط الـ Regex لا يطابق صيغة الرسالة، أو Message Content Intent غير مفعّل | فعّل *Message Content Intent*. انسخ نص رسالة ProBot الحقيقية وعدّل الـ Regex (يجب أن يحتوي `(?<amount>…)`)، أو زر «استرجاع النمط الافتراضي». استخدم زر «تحقق يدوي» للستاف أو اجعل وضع التأكيد «يدوي» |
| ProBot: «المبلغ ناقص» رغم التحويل | الضريبة لم تُضف للمبلغ | الصحيح أن يحوّل العميل المبلغ المعروض (بعد تعويض الضريبة)؛ راجع نسبة الضريبة في طريقة الدفع |
| **اللوحة لا تتزامن** (تغييرات لا تظهر في البوت) | البوت لا يقرأ المهام (متوقف أو يشير لقاعدة بيانات أخرى)، أو `DATABASE_URL` مختلف بين اللوحة والبوت | تأكد أن الاثنين على نفس القاعدة. تحقق من جدول `BotJob`: الحالات `pending` المتراكمة = البوت لا يعمل، و`failed` = راجع عمود `error`. الإعدادات تنعكس خلال ~5 ثوانٍ |
| «لا أملك صلاحية الإرسال في هذه القناة» عند النشر | صلاحيات القناة | امنح البوت View/Send/Embed Links في القناة |
| فشل إنشاء تذكرة الطلب | البوت بلا «إدارة القنوات»، أو الكاتيجوري ممتلئة (50 قناة) | امنح الصلاحية، استخدم كاتيجوري أخرى |
| الرتبة لا تُمنح بعد الدفع | رتبة البوت أدنى من الرتبة المطلوبة | ارفع رتبة البوت فوقها ثم اضغط «إعادة التسليم» |
| المفتاح لا يصل بالخاص | خاص العضو مغلق | يُرسل المفتاح داخل التذكرة تلقائياً؛ وللعميل «طلباتي» لإعادة الإرسال |
| تقرير/ملخص لم يصل | قناة التقارير غير محددة أو بلا صلاحية، أو البوت كان متوقفاً وقت الجدولة | حدد القناة، وستُرسل عند عودة البوت في نفس اليوم؛ أو استخدم «إرسال الآن» |
| الرسوم في التحليلات فارغة | لا يوجد تجميع بعد | تُجمّع ليلاً لليوم السابق؛ استخدم «إعادة تجميع أمس» من تبويب الصحة |
| لا يعمل حجب الروابط | الوحدة/الميزة معطّلة، أو العضو ستاف/مستثنى، أو *Message Content Intent* غير مفعّل | فعّل الميزة والـ Intent، وجرّب بحساب عادي |
| قائمة الحظر لا تتحدث | تعذّر الوصول لمصادر القوائم | ستُستخدم القائمة الاحتياطية؛ عيّن `SHIELD_BLOCKLIST_URLS` بمصادر تعمل |
| خطأ بناء Prisma `P1012` | كتلة في `schema.prisma` مكتوبة في سطر واحد | اجعل كل كتلة (`generator`/`datasource`/`model`) متعددة الأسطر |
| فشل بناء Vercel يذكر `Dockerfile`/`buildah` | المشروع استُورد من الجذر | في إعدادات المشروع اجعل **Root Directory = dashboard** |
| تسجيل الدخول للوحة يفشل | Redirect URI أو `NEXTAUTH_URL` خطأ | أضف `…/api/auth/callback/discord` في Discord OAuth2 وطابق `NEXTAUTH_URL` |
| لا أرى السيرفر في اللوحة | لا تملك Manage Server ولا رتبة «إدارة اللوحة»، أو البوت غير مضاف | أضف البوت للسيرفر وامنح الصلاحية/الرتبة |
