# ✅ قائمة الجاهزية للإنتاج

## الأمان
- [ ] `.env` غير مرفوع إلى Git، والتوكن/الأسرار محفوظة في إعدادات الاستضافة فقط
- [ ] `NEXTAUTH_SECRET` عشوائي وطويل، و`NEXTAUTH_URL` هو الدومين النهائي (https)
- [ ] `OWNER_IDS` مضبوط (معرّفك فقط) في البوت واللوحة، وتم فتح `/admin` والتأكد أن غيرك لا يدخل
- [ ] رتبة البوت أعلى من الرتب التي يمنحها/يسحبها، وليست أعلى من اللازم (تجنّب Administrator في الإنتاج)
- [ ] رتب الستاف محددة بدقة، ورتبة «إدارة اللوحة» لمن تثق به فقط
- [ ] عدّلت `allowDomains` في الحماية لنطاقاتك الموثوقة وجرّبت أن رابطاً عادياً لا يُحذف

## قاعدة البيانات والنسخ
- [ ] `npm run db:push` نُفّذ بعد آخر تحديث للمخطط
- [ ] نسخ احتياطي يومي يعمل (`scripts/backup.sh`) وجرّبت الاستعادة مرة
- [ ] مساحة القاعدة ومدة الاحتفاظ مناسبة (جداول الرسائل/النشاط تكبر مع الوقت)

## التشغيل
- [ ] البوت يعمل تحت PM2/Docker بإعادة تشغيل تلقائية، و`/health` يردّ 200
- [ ] مراقب UptimeRobot على `/health` مع تنبيه بريدي
- [ ] لوحة المالك `/admin` تُظهر «🟢 متصل» ونبضة حديثة
- [ ] قنوات السجلات (العام/الطلبات/التذاكر/الحماية/الستاف) محددة وللبوت صلاحية الكتابة فيها
- [ ] قناة المتجر ولوحة التذاكر منشورتان، وكاتيجوري التذاكر للبوت عليها «إدارة القنوات»

## المدفوعات (اختبر كل طريقة مفعّلة بمبلغ صغير)
- [ ] فودافون كاش: رقم صحيح، إيصال → بطاقة ستاف → تأكيد → تسليم، وإيصال مكرر يُرفض
- [ ] ProBot: المستلم/معرّف البوت/الـ Regex صحيحة (جرّب تحويلاً حقيقياً)، والضريبة محسوبة
- [ ] التسليم: رتبة (البوت أعلى منها)، مفتاح (مخزون كافٍ + حد تنبيه)، رسالة، يدوي
- [ ] انتهاء الطلب غير المدفوع واسترداد/إلغاء طلب يعملان
