# اختبار يدوي لدورة الطلب الكاملة (الخطوة 3)

التجهيز: `cd bot && npm run db:push && npm run seed:store -- <guildId>` ثم شغّل البوت.
من لوحة التحكم: الإعدادات ← رتب الستاف + قناة سجل الطلبات · المتجر ← لوحة المتجر (اختر قناة + كاتيجوري التذاكر) ← «حفظ + نشر».
استخدم حساباً عادياً (ليس أدمن) كعميل، وحساب ستاف للتأكيد.

## أ) فودافون كاش
1. اضغط «اطلب الآن» ← تُفتح قناة `طلب-1001` للعميل والستاف فقط.
2. اختر المنتج ← الباقة ← أجب عن الأسئلة (مودال) ← «عندي كوبون» أدخل `WELCOME10` ← تأكد من الخصم ← «تأكيد والمتابعة».
3. اختر «فودافون كاش»: يظهر الرقم والمبلغ الصحيح (مع الرسوم). اضغط «رفعت الإيصال» وأرسل صورة.
4. المتوقع: بطاقة ستاف فيها الصورة وأزرار ✅/❌/📷. أرسل **نفس الصورة** في طلب آخر ← يُرفض كمكرر.
5. ستاف: اضغط ❌ مع سبب ← يعود الطلب لـ «بانتظار الدفع». ثم أعد الإيصال واضغط ✅ ← «تم استلام الدفع» ثم التسليم.
6. تحقق: عميل عادي يضغط ✅ ← «ليست لديك صلاحية».

## ب) ProBot (تلقائي)
1. فعّل الطريقة وضع `recipientId` ومعرّف ProBot الصحيح من لوحة المدفوعات.
2. اختر الطريقة ← يظهر المبلغ بعد تعويض الضريبة. حوّل مبلغاً أقل ← «المتبقي». حوّل الباقي ← تأكيد تلقائي.
3. حوّل لشخص آخر ← تحذير «مستلم خاطئ». حوّل زيادة ← تنبيه للستاف.
4. اضغط «ProBot لم يرد؟» ← يُنبَّه الستاف ويظهر «تحقق يدوي».
> إن لم يُكتشف التحويل: انسخ نص رسالة ProBot وعدّل الـ Regex في لوحة المدفوعات (يجب أن يحتوي `(?<amount>...)`).

## ج) العملة المخصصة
مثل (ب) لكن بمعرّفات/نمط/سعر تحويل خاص بها؛ وجرّب وضع «يدوي» ← زر «تم التحويل» ← بطاقة ستاف.

## د) التسليم والإغلاق
- رتبة دائمة/مؤقتة (يُنشأ Subscription) · مفتاح (يصل بالخاص؛ أغلق الخاص لترى الاحتياط داخل التذكرة) · رسالة · يدوي (زر «تم التسليم»).
- بعد التسليم: تقييم ⭐ مرة واحدة، «إغلاق التذكرة» ← ملف transcript.html في قناة سجل الطلبات.
- «طلباتي» (على لوحة المتجر) ← قائمة خاصة + إعادة إرسال المفتاح.
- «استرداد/إلغاء الطلب» (ستاف) ← مع سبب؛ يُسحب الدور ويُرجع المفتاح إن كان غير مُسلَّم.
- انتهاء الطلب: اترك طلباً بلا دفع (اجعل مهلة الانتهاء 5 دقائق من إعدادات المتجر) ← تحذير ثم حذف التذكرة.
- الاشتراكات: غيّر `expiresAt` في جدول Subscription إلى بعد يومين ثم شغّل job `store:subscriptionSweep` ← DM تذكير بزر «تجديد».
